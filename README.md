# Bootstrap Integration Lab

A Django web application for an online course platform styled with Bootstrap 4.

## Key Features
* **Responsive Navigation Bar:** Dynamic navbar with login, registration, and logout controls based on user authentication state.
* **Course Catalog (`course_list.html`):** Bootstrap card deck layout displaying course images, titles, enrollment counts, descriptions, and enroll buttons.
* **User Authentication (`user_login.html` & `user_registration.html`):** Styled Bootstrap forms with validation alert banners (`alert-warning`).
* **Course Details (`course_detail.html`):** Structured course and lesson cards built with Bootstrap components.

## Tech Stack
* Python & Django
* HTML5 & Bootstrap 4
* SQLite
